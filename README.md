## 📌 Overview  

**Travel-agent** is an AI-driven multi-agent travel planning system written in Python.  
It coordinates multiple specialized “agents” — flights, hotels, itineraries — to automatically generate a customized travel plan based on user preferences.

This project is fully modular, making it easy to extend with new agents and capabilities.

---

## 🧠 Key Features  

### 🛫 Flight / Transportation Agent  
Finds travel options based on location, price range, preferred dates, etc.

### 🏨 Hotel Agent  
Recommends personalized lodging options and accommodations.

### 🗺️ Itinerary Agent  
Builds structured day-by-day itineraries including attractions, activities, and scheduling.

### 🧩 Root Agent  
Orchestrates all sub-agents, merges their outputs, and delivers a final, cohesive travel plan.
